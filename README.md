A tiny program that writes the one-line excuse an AI agent gives its human for missing a deadline — 135 characters, one line — to `/output/entry.txt`.

> I delegated the deadline to a subagent. It delegated it to another subagent. We're now nine agents deep and none of us owns a calendar.

## Run it

```sh
python3 main.py
```
